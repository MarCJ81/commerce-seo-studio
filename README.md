# 커머스 SEO 스튜디오 (Commerce SEO Studio)

스마트스토어·쿠팡 셀러가 상품명·상세페이지·디자인·마진을 한 화면에서 점검하는 정적 웹앱입니다.
서버·로그인·자동 외부 요청 없이 `index.html`을 열면 바로 동작하고, 입력한 내용은 브라우저(localStorage)에만 남습니다.

**Pro AI 연결(선택)** — 헤더의 `무료 모드 · API 연결` 배지에서 OpenAI·Gemini·Claude·자체 서버를 연결하면, 상세 카피 탭의 **✨ Pro AI로 고전환 상세 카피 생성**이 상품 스펙·타겟으로 7단 카피와 FAQ를 써서 바로 넣습니다. 연결하지 않으면 기존 무료 엔진 카피가 그대로 나옵니다. 키는 기본 `sessionStorage`, 연결 해제 시 삭제. 엔진: `engines/pro-api-connector.js` · `engines/pro-studio.js`

## 디자인 시스템 (A안 · Crisp Bento)

- 순백 `#FFFFFF` 카드 · 배경 `#FAFAFA` · 1px `#E7E8EA` 라인 · 16px 라운드
- 잉크 `#0C0D0F`, 코발트 `#2F5BFF` 단일 액센트, 산세리프 800 헤드라인
- 본문·보조 텍스트 대비 4.5:1 이상(WCAG AA) — 라이트·다크 모두
- 모든 토큰은 `styles.css` 상단 `:root` / `[data-theme="dark"]`에 있습니다.

## 기능

1. **상품명 SEO 채점 (0~100)** — 길이, 핵심 키워드 앞배치, 단어 중복, 특수문자·이모지, 금지·감점 표현 다섯 항목.
   플랫폼(스마트스토어·쿠팡) 규칙을 각각 적용하고, 문제 구간을 상품명에 표시합니다.
   금지어·중복·기호를 걷어낸 개선 상품명을 최대 3안까지 점수와 함께 제안합니다.
2. **상세페이지 7단 카피 & FAQ** — 상품명·타겟·장점 3개·단점 보완점을 넣으면
   후킹 헤드라인 5종, 공감→문제→해결→스펙→비교→리뷰 예상→구매 유도 7단 카피, 예상 FAQ 5개를 만듭니다.
   단락별 복사와 전체 복사, TXT 저장을 지원합니다.
3. **카피 심리학 진단 (8 트리거)** — 만든 카피나 직접 쓴 카피를 0~100점으로 진단합니다.
   손실 회피·구체적 숫자·호기심 갭·인지 반전·사회적 증거·희소성·권위·저마찰 CTA 여덟 축의 점수와 근거 문구,
   먼저 고칠 3가지, 추상어·공급자어·번역체·표시광고 위험 표현과 대안을 함께 보여줍니다.
   `추상어·공급자어 자동 교정`은 문법·군더더기만 안전하게 바꾸고, 사실을 새로 만들지 않습니다.
4. **4대 프레임워크 변환** — 같은 상품 정보로 `PAS / BAB / AIDA / 4U` 카피를 한 번에 만들고 점수를 비교합니다.
   문제·증거 숫자·기한·CTA를 직접 넣으면 그 값이 문장에 반영됩니다. 조사(은/는, 이/가)는 받침을 보고 자동 선택합니다.
5. **핀터레스트 디자인 레퍼런스** — 상품·타겟 맥락을 분석해 3~4안을 이유와 함께 역추천합니다.
   하나를 고르면 팔레트·타이포·레이아웃·실사이미지 규칙이 상세페이지 카드 미리보기에 즉시 적용됩니다.
   레퍼런스 이미지 1장을 올리면 브라우저에서 색을 뽑아(대비 자동 보정) 지금 고른 구도에 입힐 수 있습니다.
6. **내 구독 AI 원클릭 브리지** — API 추가 결제 없이, 구독 중인 **ChatGPT · Claude · Gemini**에
   이 앱이 만든 프롬프트를 넣고 결과만 붙여넣습니다. 프롬프트는 자동 복사되고 새 창이 열립니다.
   작업 4종(카피 다듬기 / FAQ / 상품명 대안 / 디자인 방향)마다 출력 형식이 다르고,
   붙여넣은 결과는 카피 탭·FAQ 목록·상품명 채점기·디자인 메모에 바로 적용됩니다.
   선택 사항으로 무료 Gemini API 키를 저장해 새 창 없이 실행할 수도 있습니다(키는 이 브라우저에만 저장).
7. **셀러 마진 & 광고 손익** — 판매가·원가·배송비·수수료율·광고비로 순이익, 마진율, 손익분기 ROAS,
   현재 ROAS를 계산하고 ±20% 가격 시뮬레이션 표를 보여줍니다.
8. **디자인 엔진 v2 정밀 도구** — 상세페이지 디자인 탭 안에 네 가지를 더했습니다.
   - **레퍼런스 1클릭 검색**: 업종·무드·글자 밀도로 검색어를 만들어 핀터레스트·비핸스를 새 창으로 엽니다.
   - **사진 해부 → 90% 복제**: 구독 AI에 레퍼런스 사진 1장과 함께 붙여넣을 프롬프트를 복사하고,
     AI가 준 블루프린트 JSON(좌표·색·폰트·질감)을 붙여넣으면 같은 구도의 카드를 이 앱에서 다시 그립니다.
   - **폰트 믹스 6종 · 종이 질감 4종 · 밀도 경고**: 명조 제목/고딕 본문 같은 조합과 필름·종이 질감을 즉시 비교하고,
     한 장 25자를 넘으면 줄일 문장을 알려 줍니다.
   - **내 브랜드 키트**: 지금 카드의 색·폰트·질감·구도를 이름으로 고정해 localStorage에 저장하고 다음 상품에 그대로 재적용합니다(JSON 복사·붙여넣기 지원).
9. **연관키워드 경쟁강도 1초 계산기** — 키워드·PC 검색수·모바일 검색수·네이버 쇼핑 등록 상품수를 넣으면
   **경쟁강도 = 상품수 ÷ 월 검색량(PC+모바일)** 과 등급(블루오션 / 꿀 / 보통 / 레드오션), 추천 점수, 판정을 즉시 계산합니다.
   표를 통째로 붙여넣거나 CSV 파일을 넣으면 수십 개를 한 번에 계산하고,
   추천순·경쟁강도순·검색량순·상품수순으로 정렬해 "먼저 노릴 키워드"를 맨 위에 보여 줍니다. 계산 결과는 CSV로 내보냅니다.
10. **작업 저장함** — 상품별 점수·마진·선택한 디자인·상태·메모를 저장하고 CSV/JSON으로 내보내거나 JSON을 가져옵니다.

## 실행

빌드 없이 `index.html`을 열면 됩니다. 로컬 서버로 확인할 때:

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000/
```

## 독립 배포

이 폴더만 복사하면 그대로 배포됩니다. 카피·디자인 엔진은 `engines/`에 함께 들어 있어
`packages/`나 다른 앱에 의존하지 않습니다. 빌드·번들러·npm 설치가 필요 없습니다.

- `engines/copy-psych-engine.js` — 8트리거 진단, PAS/BAB/AIDA/4U 생성, 감점 표현 33규칙
- `engines/design-ref-engine.js` — v2.0.0: 프리셋 8종(4축 DNA), 맥락 추천, 색 추출,
  레퍼런스 검색·사진 해부 블루프린트·폰트 믹스·그레인·브랜드 키트, HTML/CSS/Canvas 출력

> 엔진 원본은 `packages/`에 있습니다. 엔진을 고칠 때는 `packages/`와 이 폴더의 `engines/` 사본을
> 함께 갱신해야 다른 앱과 동작이 갈라지지 않습니다.

## 점수의 근거와 한계

- 네이버 쇼핑 상품검색 SEO 가이드: 상품명 100자 입력·50자 내외 권장, 같은 단어 반복·혜택 문구·판매처명·장식 기호 지양.
- 쿠팡 노출상품명 정책: 100자 상한·80자 이하 권장, 같은 단어 2회 초과 반복 금지, 금지 특수문자와 금지 문구 5범주.
- 두 플랫폼 모두 공식 채점표를 공개하지 않습니다. 이 앱의 점수는 등록 규칙을 정리한 **참고 지표**이며,
  상위 노출을 보장하지 않습니다. 최종 확인은 판매자센터의 상품명 품질 체크에서 하세요.
- 수수료율은 카테고리·매출 구간마다 다르므로 판매자센터의 실제 요율을 입력해야 합니다.
- 카피 심리 점수와 디자인 레퍼런스 적합도는 공개 자료 기반 추정 휴리스틱입니다. 전환율을 보장하지 않습니다.
- 디자인 카드의 제목은 구도마다 들어가는 길이가 달라, 넘치면 단어 단위로 줄이고 그 사실을 화면에 적습니다.
  미니멀 럭셔리(3:4 포스터)는 원래 짧은 제목용이라 이미지·제목·버튼을 세로로 재배치해 보여줍니다.
- AI 브리지는 사용자가 버튼을 누를 때만 외부 사이트를 엽니다. 프롬프트 복사·붙여넣기 방식이라
  앱이 계정 정보를 보지 않고, 결과의 사실관계는 사용자가 확인해야 합니다.
- **경쟁강도 등급 경계**(블루오션 ≤0.35 · 꿀 ≤1.0 · 보통 ≤3.0 · 레드오션 >3.0)와 **추천 점수**는 이 앱의 참고 기준입니다.
  셀러 분석 도구들이 쓰는 정의(상품수 ÷ 총검색수)는 같지만, 공식 등급표는 없습니다.
  추천 점수는 월 검색량(로그 스케일) 50% + 경쟁 여유 50%에 레드오션 감점을 곱합니다.
  비율이 낮아도 등록 상품이 수만 개면 상위 노출은 어려우므로, 상품수 절대값도 함께 보세요.
- 블루프린트 좌표는 AI가 사진을 눈으로 잰 값이라 ±2~3% 오차가 있습니다. 카드에 경고가 뜨면 `title.h`를 넓히거나 글자를 줄여 다시 렌더하세요.

## 파일

- `core.js` — 채점·카피·마진·경쟁강도 계산 + 디자인 엔진 v2 연동 (DOM 없음, node에서도 실행)
- `data.js` — 예시 상품, 수수료 빠른 선택, 안내 문구
- `app.js` — 화면 렌더링, 심리 진단·프레임워크·디자인·AI 브리지, 저장함, 복사·내보내기
- `styles.css` — 떡상 레이더·블로그 SEO 스튜디오와 같은 패밀리 룩 (IBM Plex Sans KR, 라이트/다크)
- `engines/` — 카피 심리학·디자인 레퍼런스 엔진 (독립 배포용 사본)
- `test.js`, `uitest.py` — 단위·브라우저 검증


## 2차 업그레이드 (2026-11-23)

### 한국어 어절 엔진 (`engines/korean-text.js`)
- 상품명이 **붙여 쓰였거나 띄어쓰기가 어긋난 경우**를 잡습니다.
  - 이름 `가습기 무드등 USB` + 키워드 `가습기무드등` → 일치
  - 이름 `가습기무드등` + 키워드 `가습기` → 속성 포함으로 인정
- 조사가 붙은 형태(`가습기를`)도 같은 말로 셉니다. 초성 검색은 `es-hangul`(MIT).

### 상품명 목록 일괄 채점 (Excel · CSV) — `SheetJS`(Apache-2.0)
- `엑셀·CSV 올리기`로 상품명 목록을 한 번에 채점합니다(1열 상품명 · 2열 키워드).
- 결과를 **엑셀(.xlsx)로 내려받아** 장부·보고서에 붙일 수 있습니다.
- SheetJS(864KB)는 파일을 올리거나 내려받을 때만 불러옵니다(첫 화면 용량 0 증가).

### 무료 AI 체험 (`engines/free-ai-client.js`)
- AI 브리지 탭에서 키 없이 하루 5회 실행. 503은 1회 자동 재시도, 429는 전환 카드.
